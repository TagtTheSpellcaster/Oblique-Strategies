A minimal web application providing prompts for lateral thinking and creative unblocking, inspired by the original *Oblique Strategies* deck created by Brian Eno and Peter Schmidt in 1975.

## Demo

Experience the live application at:
[https://tagtthespellcaster.github.io/Oblique-Strategies/](https://tagtthespellcaster.github.io/Oblique-Strategies/)

## Features

- Distraction-free, dark-mode single-screen interface.
- 83 curated, timeless prompts for creative unblocking across music, writing, design, and software development.
- Language switcher supporting English and Italian (English active by default).
- Minimal controls: trigger prompts via screen tap, click, Spacebar, or Enter key.
- Lightweight single-file implementation with zero external dependencies.

## Usage

1. Open the application in any web browser.
2. Click or tap anywhere on the screen, or press `Spacebar` / `Enter` to draw a prompt.
3. Switch languages at any time using the `EN` and `IT` selectors in the top-right corner.
